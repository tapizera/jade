# Jade 💎

Painel pessoal estático (HTML/CSS/JS). Sem dados pessoais no código: as listas e os links ficam salvos no navegador de cada aparelho (use Exportar/Importar).

- Publicar: Settings → Pages → Deploy from a branch → `main` / root.
- Fundo opcional: coloque uma imagem `fundo.gif` na mesma pasta (tema Jade). Sem o arquivo, o fundo fica só em degradê.
